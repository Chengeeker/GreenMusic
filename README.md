# GreenMusic

An Android music app built with Kotlin, Jetpack Compose, and Material 3.

- Music discovery, search, playlists, and favorites.
- Online and offline playback with synchronized lyrics.
- Downloads, audio tags, playback notifications, and WebDAV backup.
- Themes, dynamic colors, and font controls.

Android 7.0+ · ARM64

Track availability and audio quality depend on account permissions and service availability.
